- mesonfe v0.1.2 (in-progress):
  - Enable PEP 563 lazy annotations so the script imports on
    Python 3.9 (needed for Slackware 15.0)
  - Add module docstring to mesonfe/__init__.py so it isn't
    zero-length (silences a Slackware makepkg warning)
  - Collapse ninja progress lines in the compile output into a single
    updating status line, terminal-style
  - Translations: run the project's meson i18n targets (-pot,
    -update-po) instead of reconstructing xgettext/msgmerge commands
  - Fix build directory shown as "." in the info bar when launched
    from inside the build directory
  - Fix "Failed to open URI" when showing the dist folder after
    launching from inside the build directory
  - Add a Cancel button to the Compile, Test, and Dist panels to stop
    a running job, including parallel test and compiler jobs
  - Stop a running job's whole process tree when its output panel is
    closed, so ninja and test processes are not left running
